# Hi Tech Website (هاي تك) 🎓

الموقع التعريفي والخدمي الرسمي لمركز **هاي تك (Hi Tech)** لتقديم الخدمات الأكاديمية والجامعية:
- 🎓 مشاريع التخرج المتكاملة (برمجة، تحليل، توثيق)
- 📚 التدريس والشروحات الجامعية للمواد التخصصية
- 📝 حلول الأنشطة والتكاليف خطوة بخطوة
- 🔬 إعداد وتنسيق البحوث والأوراق العلمية (APA / IEEE)
- 📊 تصميم العروض التقديمية (PowerPoint & Canva)
- 💡 الاستشارات الأكاديمية والتدقيق اللغوي

---

## 🌟 مميزات الموقع:
- **دعم كامل للغتين (Arabic & English)** مع زر تحويل فوري ودعم اتجاه النص (RTL / LTR).
- **الوضع الداكن والوضع الفاتح (Dark / Light Mode)** بتصميم نيون عصري متجاوب.
- **نموذج طلب تفاعلي مرتبط بالواتساب مباشرة** عبر خاصية `wa.me`.
- **أداء عالي وسريع** بدون أي مكتبات ثقيلة أو تعقيدات.

---

## 🚀 تشغيل الموقع محلياً:
يمكنك فتح ملف `index.html` في أي متصفح ويب مباشرة.
